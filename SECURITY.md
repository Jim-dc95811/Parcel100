# Security

## Supported version

The current supported public version is Parcel100 1.1.

## Reporting

Do not publish credentials, tokens, private FeatureServer URLs, personal records, or other sensitive data in a public issue.

If a problem is purely a normal bug in public-service handling, a GitHub issue is appropriate. If it involves credentials or an access-control weakness, report it privately to the repository owner instead of posting exploit details publicly.

## Scope

Parcel100 is designed for public ArcGIS FeatureServer polygon layers. It does not implement authentication and should not be modified to bypass access controls.

Downloaded GeoJSON can contain owner names and addresses. Treat output files according to your organization's privacy, retention and handling requirements.
